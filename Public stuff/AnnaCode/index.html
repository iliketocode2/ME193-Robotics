Activation functions

An activation function is applied to each neuron's output before it becomes usable downstream. It introduces non-linearity so the network can learn complex patterns. One activation function is shared by every neuron. Without one, any number of neurons and layers collapses into a single line (y = mx + b); a non-linear activation stops that, so line segments can add up to curves.

None No transformation. Output passes through unchanged (identity).
ReLU y = max(0, x). Keeps positives, sets negatives to zero. Cheap, so common in deep networks, but a neuron stuck at 0 can “die” (leaky ReLU, max(0.01x, x), avoids that).
Sigmoid y = 1 / (1 + e−x). An S-curve between 0 and 1. Good for probability outputs.
Tanh y = (ex − e−x) / (ex + e−x). Between −1 and 1; being centred on zero can mean faster training.
Softplus y = ln(1 + ex). A smooth ReLU that only approaches zero, with no hard cut-off.
Custom Define your own f(x), optionally as separate pieces over different ranges of x.
