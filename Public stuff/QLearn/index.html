Running the Python versions

  1. Install Python 3 from python.org. It includes tkinter, which the dashboards use for their window.
  2. Install the two packages they need: 
    python3 -m pip install "legoeducation>=1.2.0" numpy
    On Windows, type py in place of python3.
  3. Turn on the Double Motor. Its firmware must be up to date: update it at code.legoeducation.com. Then run the file you downloaded: 
    python3 PascalQTable.py
  4. When the buttons light up, aim the robot and click Train, Run or Clear & train. Space pauses and Esc stops. What it learns is saved in a file next to the program, so the next Train carries on from there.

One difference from the web app: the Python versions give the reward for the state the robot ends up in after each step, which is standard Q-learning. The web app gives it for the state the robot started in. To match the web app, set REWARD_NEXT_STATE = False near the top of the file.
