Tally & Policy Sheet

For the policy builders · one sheet for the whole class

1. For every row on every worksheet, find that reading below and put a tally mark (|||| ) in the column for the action taken. Use a second color for corrections.
2. For each reading, circle the column with the most tallies. If it is a tie, pick the most recent row, and tick the Conflict box if both columns have any tallies.
3. Write the winning action in Policy does. That table is what the Robot will follow.
